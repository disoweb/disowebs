# Disowebs Role Dashboards (Exact Widgets + Intent)

## CEO Dashboard (Business Health)
### Widget 1: Weekly Execution Scoreboard
- Delivery: milestones done this week
- Revenue: payments received this week
- Proof: proof entries created this week
- Warning if any == 0

### Widget 2: Revenue & Cashflow
- Revenue collected (month)
- Outstanding invoices (count + sum)
- Active retainers (count + MRR)

### Widget 3: Pipeline Forecast
- Qualified leads count
- Proposals sent count
- Weighted forecast next 30/60 days

### Widget 4: Capacity & WIP
- Active projects count vs limit
- Queued projects count
- Blocked milestones list

### Widget 5: Risk Alerts
- Overdue milestones
- Overdue invoices
- Projects without scope snapshot

### Widget 6: Growth Flywheel
- Proof entries this month
- Testimonials requested/received
- Case studies ready

---

## CRM Manager Dashboard (Flow)
### Widget 1: Today’s Priorities
- Leads to follow up today
- Clients awaiting weekly update
- Invoices awaiting follow-up
- CRs awaiting CEO approval

### Widget 2: Pipeline Hygiene
- Follow-ups overdue
- Stale leads (>7 days without activity)
- Proposals pending > X days

### Widget 3: Active Projects Overview
- Current milestone
- Next update due date
- Payment status

### Widget 4: Retainer Tracker
- Launched in last 30 days
- Retainer offered
- Accepted / declined

---

## TSA Dashboard (Stability)
### Widget 1: Support Queue
- New/open tickets
- Tickets >48h
- High priority

### Widget 2: QA Readiness
- Projects awaiting QA
- QA checklist completion (if tracked)

### Widget 3: Documentation
- Projects missing docs
- Docs updated this month

### Widget 4: Proof Backlog
- Projects without proof entry
- Proof entries created this week
