# Disowebs Business OS v2 (Mid-ticket, Medium Volume)

## Objective
Operate Disowebs as a predictable, profitable company with controlled execution, retainers, and proof compounding.

## Business Model
- Deal size: ₦300k–₦1.5m
- Volume: 4–8 projects/month
- Retainers: 30–50% of clients

## Policies (enforced via process + module)
1) WIP limit: max 3–4 active projects
2) Deposit gate: 60–70% before Build phase
3) Final payment before handover credentials
4) No scope changes without Change Request
5) Proof entry required before project closure
6) Retainer offer at day 21–30 post-launch

## Engines
### Sales Engine
- Qualification gate (required fields)
- Package-based proposals
- Follow-up cadence (Day 1/3/7/14 reminders)
- Pipeline forecast (weighted)

### Delivery Engine
- Phases + weekly milestone per project
- Weekly demo requirement
- Blocker tracking with owner + next action date

### Profit Engine
- Project profit sheet (expected revenue, effort, margin)
- Margin alerts when CRs approved without impact

### Retention Engine
- Training completed checkbox
- Adoption baseline captured (simple)
- Retainer conversion tracked

### Growth Engine
- Proof → testimonial request → case study draft
- Proof backlog dashboard

## Team Roles (your current plan)
- CEO/Lead Dev: discovery, qualification, proposals, pricing, architecture, approvals
- CRM Manager: pipeline hygiene, comms, follow-ups, invoices sending, CR logging, retainer conversations
- TSA: support tickets, QA, documentation, proof capture

## KPI Targets
Weekly:
- Delivery/Revenue/Proof scoreboard never 0
Monthly:
- Projects delivered: 4–8 (quality over volume)
- Retainers added: 1–2/month until stable base
- Proof entries: 1 per delivered project
